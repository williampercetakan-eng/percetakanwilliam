# Percetakan William — Website Profil & Katalog

Website percetakan sederhana yang menampilkan profil usaha, layanan, katalog produk, dan formulir pemesanan via WhatsApp.

## Struktur File

```
index.html   → Halaman utama website
style.css    → Tampilan dan desain (warna, layout, dll)
script.js    → Fungsi menu mobile & form WhatsApp
```

## Cara Mengubah Konten

- **Nomor WhatsApp**: Buka `script.js`, ganti `6281234567890` dengan nomor Anda.
- **Alamat & Jam Buka**: Buka `index.html`, cari bagian "KONTAK".
- **Harga Produk**: Buka `index.html`, cari bagian "KATALOG PRODUK".
- **Warna Website**: Buka `style.css`, ubah bagian "VARIABEL WARNA" di paling atas.
